**AC1/AC2 violation (sync):** The sync client's `finally` block only closes the response when `stream=False`. When `stream=True`, the response is returned open. Unlike async, the sync client does not support mid-iteration cancellation via `asyncio.CancelledError`, but it must still handle timeouts during `response.iter_bytes()`. The test `test_sync_timeout_during_stream_closes_response` does not cover iteration (only `client.get(url)` with `stream=False`), so AC3 parity is incomplete: there is no sync equivalent of `test_async_cancel_during_body_iteration_closes_response` to verify sync streaming iteration cleanup.
